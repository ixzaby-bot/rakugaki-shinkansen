# テスト記録

対象: v0.1.0 / 実施日: 2026-11-21

## 実施済み

Windows環境のNode.jsで実行。依存ライブラリなし。

| 試験 | 結果 | 検証方法 |
| --- | --- | --- |
| JavaScript構文 | 合格 | `node --check script.js` |
| 短い線・タップ | 合格 | 2 px未満の入力で走行対象が作られない |
| 入力位置 | 合格 | Canvas左上オフセットを引いた座標を確認 |
| 走行速度 | 合格 | 仮想フレームの経過時間と移動距離を比較 |
| 終端折り返し | 合格 | 進行方向が反転し距離が線路長内に収まる |
| 自己交差 | 合格 | 交差する線路で600フレーム実行 |
| 閉じた線路 | 合格 | 800フレーム後も周回し距離が全長未満 |
| 複数線路 | 合格 | 過去3本を保持し、最後の閉路が走行対象 |
| サイズ変更・DPR | 合格 | 390×844→844×390で長さの倍率とバッファ寸法を確認 |
| 2本目の指 | 合格 | 描画中の別pointerIdを無視 |
| 入力キャンセル | 合格 | 未確定線を破棄し既存線路を維持 |
| 全消去 | 合格 | 描画中も線路・車両・pointer captureを解除 |
| 極小サイズへの変更 | 合格 | 1×1に縮小後も走行距離が有効範囲内 |
| 描画数値 | 合格 | Canvasへの数値引数にNaN / Infinityがない |

再実行: `node tests/smoke.cjs`

上記はDOM/Canvasを模した自動テストであり、画面を描画するブラウザ・実タッチ入力の試験ではない。

## プレビュー試行と制約

ローカル静的サーバーの起動メッセージは確認したが、ブラウザの同じloopback URLには別の既存アプリが表示され、この作業フォルダのページを確認できなかった。シェルのHTTP確認はソケットのアクセス制限により失敗。file URLでの確認もブラウザのセキュリティポリシーにより拒否された。これらは画面検証の合格に数えない。

- 縦横回転、ブラウザのアドレスバー伸縮、safe-area、文字とボタンのレイアウト。
