# 変更履歴

## v0.2.1 — 2026-11-21

- ユーザー承認により、追加指示書の複数編成版をv0.2.1として管理。公開済みv0.2.0タグは保持。
- 線路と編成の管理を分離し、線路ID・編成ID・対応線路ID・車種・距離・方向・速度・編成サイズを保持。
- 独立線路ごとに1編成を追加し、1つのアニメーションループで全編成を同時更新。過去の編成も描画中に走行を継続。
- 継ぎ足し・閉路化では同じ線路／編成IDと全車両の位置を維持。全消去とリサイズを全編成対応に変更。
- 前版の異なる2本の統合を取りやめ、橋渡しする描画は独立線路と新規編成として処理。
- 小さい端点付近の動きによる誤閉路化を抑制。接続許容距離は28 CSS pxを維持。
- 指示書T-01〜T-20に対応する自動検証、5編成、10編成1,600フレーム、既存機能の回帰テストに合格。実機の最終確認は未実施。

## v0.2.0 — 2026-11-21

- 開路の始点・終点への継ぎ足し、新しく描いた線の終点からの接続、2本の線路の統合、両端接続による閉路形成を追加。
- 28 CSS pxのファジー判定と最短候補の選択を追加。曖昧な候補・同じ端点の二重使用は独立線路へフォールバック。
- 新規区間の接続付近だけを滑らかに補間し、既存の経路・走行中の編成位置・進行方向を維持。
- 短い線路からの継ぎ足しでも既存の編成両数・サイズを保持。接続と無関係な走行中の線路からは編成を移動させない。
- 接続成功時に0.6秒の光の演出を追加。閉路化後も逆向きの周回に対応。
- v0.1.1のユーザーによる実機テスト全8項目の合格を記録。端末等の未報告情報は補完しない。
- 継ぎ足し・閉路・許容距離・曖昧判定・走行位置維持・回転の自動テストを追加し、既存テストとともに合格。
- v0.1.1のタグを維持し、v0.2.0（2231067）をGitHub Pagesの同じURLへ公開。デプロイ成功、公開ファイル一致、ブラウザでの継ぎ足し・閉路形成・光演出を確認。詳細はTEST.mdに記録。
