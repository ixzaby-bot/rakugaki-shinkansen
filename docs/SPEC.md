# 仕様 v0.3.4 — ふしぎならくがき・試作

更新日: 2026-11-25

## 座標と表示

- camera.js: WORLD_WIDTH=5000、WORLD_HEIGHT=5000、原点左上。初期中心(2500,2500)、INITIAL_ZOOM=1、MIN_ZOOM=0.5、MAX_ZOOM=3。
- カメラx/yは表示中心のワールド座標。ワールド1単位は100%時のCSS px相当。
- worldToScreen: (world-camera)*zoom+viewport/2。screenToWorldはその逆。入力はclient座標からCanvasのgetBoundingClientRect()左上を引いたCSS px。
- カメラ変更はsetCameraに集約し、境界をクランプ。表示範囲がワールドより大きい軸は中央寄せ。境界補正以外では回転後も中心と倍率を維持する。
- Canvasと経路キャッシュのバッファはviewport×DPRのみ（DPR上限3）。5000×5000バッファは生成しない。
- 毎フレームscreen用DPR変換を再設定してクリア、ワールド変換を絶対指定、描画後screen変換へ戻す。ワールド外は薄い灰色、紙は白。
- 道路→線路→描画プレビュー→全乗り物→接続光の順。静的経路レイヤーは経路・カメラ・viewport変更時に再描画する。

## データと走行

- tracks[]: 全経路で一意のid、kind（rail/road）、ワールドpoints/cumulative/length/closed、canonicalなsource、互換用scale=1。
- trains[]: 一意id、trackId、type、distance、direction、speed、carCount、baseSize。tracksByIdで対応。
- カメラ変更・リサイズ時に経路点列、source、車体サイズ、走行距離、方向を変更しない。旧版の画面への自動縮小を廃止。
- 列車は最大4両、自動車は1台。短経路は初期作成時のみ両数/サイズを調整。延長でID・位置・向き・車種・両数・サイズを維持。
- 列車70、自動車60ワールド単位/秒。1つのrequestAnimationFrameで画面外も更新。長いフレームのdtは最大0.05秒、中断復帰最初のdtは0。
- carPoses/sample/formationはワールド上の経路距離を使う。開路は折返し、閉路は周回。D51は同じ物理車両を機関車に保ち、反転時は客車を押す。自動車は進行方向へ180度反転。

## 入力とジェスチャー

- Pointer Eventsとpointer capture、touch-action:none、固定bodyで描画スクロールを抑止。
- pointers Mapで全接触を管理。idle / drawing / cameraGestureを区別。1本指とマウス左ドラッグは描画。
- 2本目のCanvas上の指で未確定点列を破棄し、カメラ操作に移る。初期中点のワールド座標・距離・倍率を保存し、現在の中点と距離から一括計算する。3本目は描画せず、使用ペアの指が離れた場合は残り2本で基準を取り直す。
- 2本→1本では描画再開しない。全指が離れた次のpointerdownで再開。cancel/lost captureでも不完全経路を残さない。
- モード変更とホームは未確定線を破棄し、接触が残る間は描画を禁止。全消去・blur・復帰は全ポインターとcaptureを解除。
- リサイズ中も確定済み幾何を維持。描画点列はワールドのまま継続、カメラジェスチャー中のリサイズでは動作基準を無効にして全指を離すまで待つ。
- マウスによるパン/ホイールズームは対象外。カメラの数学処理は入力から独立し、将来の自動スクロール等からsetCameraを呼べる。

## 経路・接続

- 点取得は画面2px以上の移動を採用しワールド境界内へ制限。確定の最小長は24ワールド単位。
- 約6ワールド単位の等間隔再サンプル＋Chaikin法2回。描画と走行は同じ平滑化済み経路。
- 独立閉路は平滑化前全長100以上・両端距離24以下（ワールド単位）。
- 同kindの開路端点だけ接続。途中分岐・異種接続・閉路への接続なし。
- 接続距離=min(MAX_CONNECT_WORLD=56, CONNECT_RADIUSまたはROAD_CONNECT_RADIUS=28 / zoom)。競合差0.5 CSS px未満は曖昧として独立経路にする。
- 同端点の二重利用や異なる2経路への橋渡しは統合しない。独立経路と新しい乗り物を1つ追加する。
- 4方向の接続で旧経路の向きを保ち、新区間の接続付近だけ最大16ワールド単位の接線補間。旧経路を再平滑化しない。接続時0.6秒の光。
- 同じ開路の反対端同士の接続は閉路化。ただし新区間長40未満、範囲対角28未満、結合後100未満を除外。

## UI・車両

- 初期せんろ/はやぶさ、道路初期パトカー。モード別選択を保持。新規経路確定時だけ選択typeを生成する。
- 列車: hayabusa / komachi / kagayaki / nozomi / d51。自動車: police / fire / ambulance / bus / minivan。
- vehicles.jsのCanvasオリジナルイラスト。公式ロゴ・画像なし。道路は基本外幅36、舗装32、破線10/12ワールド単位で車体倍率に連動し、カメラ倍率も一緒に適用。
- 既存5枠選択バー、モード、全消去に加え「⌂ まんなか」とズーム百分率、2本指案内を追加。UIはCanvasと別要素。
- ホームは中心と100%のみ復元。全消去は両kindの経路・車両・時間・ID・接続演出を消去するが、カメラ・モード・車種を保持。

## 復帰と制約

- visibilitychange / pageshow / contextrestoredで時間・入力をリセットし、viewportバッファと経路キャッシュを再構成する。contextlostは既定処理を抑止して再描画待ちにする。
- 長時間Safari復帰(C-32)は未検証。過去の線路非表示の原因未特定で、今回の対策を解消確認とは扱わない。
- 外部依存・ビルド・保存なし。踏切、停止、信号、部分消去、慣性、ミニマップは未実装。
- 極端なカーブの重なり/車体はみ出し、数の上限なしは既存制約。実機性能は別途確認。

## v0.3.2 エッジスクロールとガイド

- edge.js: SIZE=48 CSS px（4辺共通）、MAX_SPEED=240 CSS px/秒/軸、DELAY=0.15秒、MAX_DT=0.1秒。ガイド用CSS変数--edge-sizeもSIZEから初期化。
- 発動はdrawing、接触1本、Canvas内の最後のCSS座標、有効な経路点列、UI上でない場合のみ。画面の四隅では各軸を独立処理。
- 速度は240×近接率²。近接率=(48-端までの距離)/48を0〜1に制限し、画面座標速度×dt/zoomでカメラを動かす。待機終了をまたぐフレームは終了後の時間分のみ移動。
- 既存のカメラ境界関数を共用し、移動できない軸は停止。カメラが動かない場合は同一点や再描画要求を増やさない。
- 既存requestAnimationFrame内で、カメラ移動→境界→screenToWorld→点追加→描画を実行。追加閾値2 CSS px、長いステップはmin(6ワールド単位,6/zoom)以下へ補間する。pointermoveがなくても点を追加。
- エッジ用dt上限は0.1秒（10FPSまでは時間基準速度を維持）。それより長いフレームは暴走防止を優先し低速になる。既存車両のdt上限0.05秒は維持。
- Canvas外への移動、2本指、up/cancel/lost capture、モード・ホーム・全消去、blur/復帰で停止。UI下へドラッグした場合はelementFromPointで判定して自動移動停止。別の指でUIへ触れる場合は未確定線を取消。
- リサイズでは最後のエッジ座標を無効にする。新しいpointermoveで正しいCanvas矩形に基づいて再開。
- F-15は添付F-14の任意表示より優先する。上下左右の常時グラデーションはposition:absolute/inset:0で画面固定。淡い琥珀色#e8aa42、単一要素全体opacity=.13により4隅も13%を超えない。
- ガイドはpointer-events:none、aria-hidden。Canvasの上、操作UIの下に重ねる。判定や描画可能範囲を狭めない。境界停止やズームで表示のオン/オフを行わず点滅を防ぐ。


## v0.3.3 消しゴム

- activeTool=draw/eraseをmode=rail/roadと分離。初期draw。「けす」でトグル、kindボタンでdrawへ。車種・kind選択、カメラを保持する。消去後もeraseを維持。
- 経路選択はfindPathAtPoint、削除はremovePath(id)。hit.jsは副作用なしの線分距離、閉路の最終線分、ゼロ長線分を扱う。
- 経路判定は平滑化済みpointsを使用。幅は線路26ワールド単位（枕木と線幅）、道路36×formation.scale。半幅に12 CSS px / zoomを加算。中心線の最近傍を選び、最短距離との差0.5 CSS px以内は選択kind、実描画順（道路の上に線路、同種では後の経路）を優先。
- 車体を明確に押した場合は所属経路を優先。実描画と共通の姿勢・role・縮尺でローカル座標へ逆変換し、車種別の簡略シルエットを判定。車両配列・編成内の逆順で手前優先。車体への余白は加えず、画面外・UI上の入力を除外。新幹線の鼻は内側寄りのテーパー近似で、ピクセル単位の輪郭一致ではない。
- pointerdownでは候補IDを記録し赤色で強調するだけ。pointerupで再判定し同一IDの場合のみ最大1本削除。移動中の候補再選択や連続削除はしない。
- 開始点から最大12 CSS pxまで。coalescedサンプル・up位置も検査し、一度超えたら戻しても無効。2本指・cancel/lost capture・Canvas外/UIへの移動・モード変更・リサイズ・復帰で取消。2本指は既存パン/ピンチへ遷移し、全指離しまで単独消去を再開しない。
- removePathは対応する全乗り物、配列、ID Map、接続演出を整理し、経路キャッシュを無効化。未知のIDはfalse。他の経路/乗り物やID採番を変更しない。
- erase中はエッジガイドをhiddenにし、drawing状態を開始しないため自動移動しない。ヒットテストはdown/upのみ。候補描画は既存RAF内。
- 部分消去・分割・undo/redoは対象外。実タッチの最終完成判定はユーザー確認後。


## v0.3.4 追加概要

- activeTool=sketchで複数筆を保持。入力・カメラ・エッジ移動を再利用。現在の一筆のみ取消、乗り物は生成しない。
- recognizer.js：各6種×3お手本。線分長で64点にリサンプル、最大辺で等比正規化、双方向最近傍平均距離＋縦横比差で比較。上下方向は維持、筆順依存は小さくする。総延長40 CSS px未満/短辺10 CSS px未満は変身せず案内。
- scenery.js：外接矩形中心・寸法から固定縦横比で生成。高さ最低30、最大辺650ワールド単位、世界の境界内に収める。0.4秒の軽い拡縮。背景→オブジェクト→経路→乗り物→らくがき→UI。
- 消去は経路・車体を優先し、ヒットしない時だけオブジェクト矩形を手前順に判定。object-付きIDで経路IDと分離。全消去は筆・オブジェクトも対象。
- 色/太さ選択、候補選択、部分消去、保存、衝突は対象外。認識精度の詳細評価は行わない。
