# らくがき新幹線 v0.2.2

2〜5歳児向けの、指で描いた線路を選んだ列車が走るプロトタイプです。HTML / CSS / JavaScript / Canvasのみで動作し、外部ライブラリ・API・通信・広告・保存機能はありません。

## 公開先

- ゲーム: https://ixzaby-bot.github.io/rakugaki-shinkansen/
- GitHub: https://github.com/ixzaby-bot/rakugaki-shinkansen
- 公開するゲームのバージョン: v0.2.2（5車種選択版）。リリースのコミットは同名のGitタグから確認できます。公開後の検証記録は後続コミットで管理します。
- 追加指示書の目標表記はv0.2.0でしたが、同タグの公開済み履歴を保持するため、ユーザー承認によりv0.2.1として管理しています。
- GitHub Pagesの公開元: `main` ブランチの `/ (root)`。

## 起動方法

PCでは `index.html` をブラウザで開くだけで遊べます。ビルドやインストールは不要です。

iPhone / iPadでは上記のゲームURLをSafariで開いてください。別リポジトリで公開する場合のGitHub Pages設定手順は次のとおりです。

1. このフォルダのファイルをGitHubリポジトリにpushします。
2. リポジトリのSettings → Pagesで、公開元を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` に設定します。
3. 発行されたURLをSafariで開きます。

相対パスのみを使っているので、リポジトリ名を含むURLでも動作する構成です。

## 車両選択（v0.2.2）

画面下のイラストと名前をタップし、はやぶさ・こまち・かがやき・のぞみ・D51を選びます。初期選択ははやぶさです。新しい独立線路だけに選択車種を生成し、既存編成や継ぎ足した編成の車種は変えません。全消去・画面回転でも選択を維持します（リロードで初期化）。

D51は機関車1両と客車最大3両です。折り返し時は機関車の向きを変え、同じ車両位置から客車を押す運転になります。煙・音はありません。

## 操作方法

- 白い画面を指一本、またはマウスの左ドラッグでなぞります。
- 指を離すと線路が確定し、新幹線が自動で走り出します。独立した線路を描くたびに1編成増え、すべての編成が同時に走り続けます。
- 描いた線の細かなブレを補正し、先頭車・中間車2両・最後尾車の最大4両編成が走ります。短い線路では両数と大きさを自動調整します。
- 開いた線路は端で折り返します。始点の近くまで戻って描くと周回します。
- 既存の線路の端から描き始めるか、端に向かって描き終えると継ぎ足せます。同じ線路の両端を結ぶと周回線路にできます。継ぎ足し・閉路化では編成は増えません。
- 接続が成功すると接続箇所が短く光ります。走行中にも追加でき、走っている編成の位置は保たれます。
- 別の独立線路を描いても、以前の線路と新幹線は残り、描画中も走行します。線路はすべて同じ濃さで表示します。
- 異なる2本の既存線路を橋渡しする線は、今回は統合せず独立線路として追加します。その場合は新しい編成が1つ増えます。
- 「ぜんぶけす」で線路と車両を消し、最初から遊べます。
- 短すぎる線やタップでは新しい線路を作らず、以前の走行を継続します。

## 検証

Node.jsがある環境で `node --check script.js`、`node --check vehicles.js` と `node tests/smoke.cjs` を実行できます。自動テストはDOMとCanvasを模した環境で入力・走行計算を検証するもので、実際のブラウザ描画やSafari実機試験を代替しません。詳細は [テスト記録](docs/TEST.md) を参照してください。

## 既知の制約

- v0.1.1はユーザーの実機テスト全8項目で合格しています。端末・OS・ブラウザの詳細は報告されていません。v0.2.1の複数編成・継ぎ足しはユーザー実機未確認です。最終完成判定はiPhone / iPad実機テスト後に行います。
- 公開ブラウザで5／10編成・継ぎ足し・全消去を確認済みです。長時間中断した検証タブの復帰時に線路が一度非表示になり、再読み込みで復帰しました。原因は未特定で、実機でのバックグラウンド復帰確認が残っています。
- 接続許容距離は `script.js` の `CONNECT_RADIUS`（28 CSS px）で調整できます。近い候補が同距離（差0.5 px未満）の場合や同じ端点へ両端を接続する場合は、独立線路として扱います。
- 接続時に車両が急に増えたり大きくなったりしないよう、編成の両数・サイズを維持します。短い線路を伸ばしても両数は増えません。新しい独立線路を描くと長さに合わせて再設定します。
- 車両の中心は補正済み経路上を通りますが、極端な急カーブでは車体が線路からはみ出したり、車両同士が重なる場合があります。車体の衝突判定はありません。
- 線路は局所的に平滑化した細かい折れ線です。非常に急な折り返しでは2本のレールが重なることがあります。
- 全長100 CSS px以上で、終点が始点から24 CSS px以内の場合に閉じた線路と判定します。意図せず周回になる場合があります。
- 画面サイズ変更では描画時の元座標から毎回計算し、線路と編成を同じ倍率で中央に収めます。元の画面サイズへ戻すと元の大きさに戻ります。小さな画面では車両も小さく表示されます。
- 自己交差は描いた順序どおり走行します。線路途中への分岐・交差点の進路選択・閉路への追加接続はありません。
- 線路数・編成数・入力点数の上限は設けていません。10編成の自動テストは実施しましたが、スマートフォンの描画性能を保証するものではありません。長時間描き続けて重くなった場合は「ぜんぶけす」を使用してください。
- 走行音・衝突判定・個別削除は未実装です。v0.2.2の車種選択とD51は実機未確認です。
- 画面端では車体が一部隠れます。タイトル・ボタン付近は表示と線路が重なる場合があります。
- リロードやページを閉じると描いた線路は失われます。
